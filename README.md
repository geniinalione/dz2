# Система управления рецептами

Классы для работы с рецептами и списком покупок: Ingredient, Recipe, DietaryRecipe, ShoppingList.

## Возможности
- Ingredient — ингредиент с проверкой количества
- Recipe — рецепт с добавлением ингредиентов и масштабированием
- DietaryRecipe — рецепт с типом диеты
- ShoppingList — список покупок с суммированием ингредиентов

## Установка

pip install -r requirements.txt


## Запуск тестов

pytest


## Структура
- recipes.py — классы
- test_recipes.py — тесты
